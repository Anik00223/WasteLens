Technical Architecture

Edge AI & Dual-Head Rejection

Model Architecture & Quantization
WasteLens is built upon an ImageNet pre-trained MobileNetV2 backbone with depth multiplier 1.0. The feature representations are frozen, and a custom dual-head network is trained on top:
  • Input Shape: $224 \times 224 \times 3$, normalized via $(x / 127.5) - 1.0$ strictly into $[-1.0, 1.0]$.
  • Classification Head: 4 units with Softmax activation predicting categorical distribution over waste streams.
  • Rejection Head: 1 unit with Sigmoid activation estimating $P(\text{unsupported})$.
  • Client-Side Engine: Executed natively inside the browser using TensorFlow.js 4.22.0 with WebGL hardware acceleration.
Calibrated OOD Decision Logic
To prevent the notorious overconfidence of standard softmax classifiers on out-of-scope scenes, WasteLens enforces a priority decision ladder:
  • Rejection Gate (Priority 1): If $\text{reject} \ge 0.0702$, the input is flagged Unsupported regardless of classification confidence.
  • Ambiguity Gate (Priority 2): If $\text{score}_{\text{top}} < 0.60$ or $(\text{top} - \text{second}) < 0.50$, flagged Uncertain.
  • Acceptance (Priority 3): Otherwise confirmed as Supported.
  • Multi-Region Analysis: 8-window spatial proposal grid with IoU suppression ($0.30$ same-class, $0.60$ cross-class).

Empirical Real-World Validation Findings

WasteLens maintains technical honesty regarding edge classification limitations. A formal 13-image empirical benchmark evaluated under headless Chrome established a finding of READY WITH LIMITATIONS:
  • Quadrant Duplication on Centered Items: Large centered items overlap non-adjacent quadrants ($\text{IoU} < 0.30$), occasionally producing 3 to 5 candidate region boxes for a single item.
  • Bridging Center Proposals: The central proposal window spans separated objects, generating an extra bridging proposal between distinct items.
  • Domain Shift False Rejection: Domestic countertops or textured asphalt drift from studio training framing, occasionally scoring above the $0.0702$ threshold on valid waste.
  • Trained Object Detection (Future Work): True bounding-box localization (YOLOv8-nano) requires dense regression anchors and is planned for future iterations.
